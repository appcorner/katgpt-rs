# Issue 919: Spike Census + Delimiter-Sink Constancy PoC (Research 605)

**Status:** Active — POC filed from Research 605 (arXiv:2603.05498, "The Spike, the Sparse and the Sink", ICML 2026)

## Summary

Modelless, weight-only extractions from the paper's causal anatomy, PoC-gated before any promotion toward a quant GOAT plan. Ordered by expected value: **the census → per-channel quant exemption is the primary deliverable** (it closes 487's Q8KV per-block-absmax gap); the sink-constancy probe is secondary and rescoped to the class where folding is actually open.

1. **Weight-derived spike census (primary).** The paper shows massive activations are generated by 1–2 early "step-up" FFN blocks (cancelled by late "step-down" blocks) through directional quadratic amplifiers: spike channels ⇔ large `‖U_k‖_F` where `U_k = Σ_i W_down(k,i)·W_gate(i)·W_up(i)ᵀ`, with all spike channels sharing one trigger direction `s⋆`, and `W_down` carrying anomalously large entries at collinear gate/up rows. Screening stat per candidate `(k,i)`: `s = |W_down(k,i)| · ‖γ⊙W_gate(i)‖ · ‖γ⊙W_up(i)‖` (dominant singular value of the rank-1 term). **γ MUST be folded in**: GGUF stores the RMSNorm scale separately (Gemma uses the `(1+γ)` convention) — the paper omits it only because it absorbs into the next weight matrix; scoring raw `W_gate`/`W_up` reads the wrong matrices. Output = a tiny BLAKE3-committable sidecar (blocks × channels × trigger direction), computed from GGUF weights alone — no calibration activations (the delta vs AWQ-class pipelines). The stat is an approximation (dominant-rank-1 argument; the paper measures exact `‖U_k‖_F`) — T2's validation gates any use.

2. **Delimiter-sink constancy (secondary, rescoped).** Position-0 sink K/V are bit-identical across prompts **by construction** (causal mask ⇒ position 0 sees only itself; RoPE at position 0 is identity) — prefix caching and ShardKV's lossless sink storage (Plan 147) already exploit this; folding that row saves one row per (layer, head) and pins it at full precision (the KVSink/IntactKV posture we already have). **The open class is delimiter sinks** (self-sinking delimiters at varying positions): post-RoPE K cannot fold (position-dependent); the candidate constants are **pre-RoPE K and V** plus a per-sequence sink-position list. The paper never quantifies K/V constancy (its cos ≈ 1.0 is hidden-state post-step-up over 1024 C4 sentences) and never for delimiters — hence the probe.

## Tasks

- [ ] **T1 — census implementation (primary).** Offline scan over a loaded GGUF: per FFN block, threshold scan on `|W_down|` with **the stored per-block γ folded into gate/up rows**; score collinear-gain candidates; emit census sidecar (spike channels + step-up/step-down block indices + `s⋆`). **Named arm: the Bonsai scale-aware variant** — ternary `W_down` entries are `{−1, 0, +1}` × group scale, so an entry-magnitude scan collapses; score dequantized weights or the group scales directly. Block-locality check against the paper's Table 1 pattern (1–2 early, 1–2 late).
- [ ] **T2 — census validation (primary).** One calibration forward per model: per-channel max activations at predicted blocks; census precision/recall. Targets: gemma-2-2b-it (falsifiable prediction: sandwich-family norms ⇒ weaker spikes than a Llama-class 2B; GeGLU — quadratic approx holds since `GELU(x) ≈ x` for large positive x, but the amplifier constant differs; γ via `(1+γ)`), a Qwen3.8-class FA model, and **Bonsai via the scale-aware arm**.
- [ ] **T3 — census → quant policy (primary, expected-value center).** Per-channel scale exemption / mixed precision exactly on census channels of census blocks in the quant lanes (riir-infer EXL3/GDN consumption cross-ref); measure quality at equal bit budget vs per-block absmax (the 487 Q8KV gap). This is the measurable-gain leg — GOAT-gate it here first.
- [ ] **T4 — delimiter-sink constancy probe (secondary).** Delimiter-class sinks only (not position 0 — that class is exact by construction and tells us nothing): across N prompts × layers × heads, extract **pre-RoPE K and V separately** per sink position; measure cross-prompt cosine + effective subspace rank (paper: keys collapse to 1–2 dims of `W_K` row space). Go/no-go bar: cos > 0.99 per class.
- [ ] **T5 — delimiter folding prototype (only if T4 passes; conditional follow-on, not the main deliverable).** Store pre-RoPE sink K/V as per-(layer,head) constants; apply RoPE at the sink's runtime position (a rotation, not a recompute); keep the per-sequence sink-position list; quantize the constant rows offline at full precision. Compare KV memory + eval quality vs the ShardKV lossless-sink baseline. Expected memory delta is small (one row per sink per layer/head); the quant-precision and eviction-safety wins are the actual claim.
- [ ] **T6 — merge-drift census runs (pointer).** The merge gate is owned by **riir-train Issue 614 T4** (where merges happen); this issue supplies the census artifact it consumes (run before/after one real merge, report inflation or no-inflation).
